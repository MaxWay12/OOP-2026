# Лабораторные работы по ООП

Сборник семи лабораторных работ по дисциплине «Объектно-ориентированное программирование» на C++. Все работы собираются в одно консольное приложение `oop_labs.exe` с меню выбора задания.

## Функциональность

- Объединение, замена строк и добавление символов
- Вывод строки в заданной позиции консоли
- Обработка текста с помощью указателей
- Динамическое создание объектов и массивов
- Демонстрация наследования и виртуальных функций
- Перегрузка функций и операторов
- Обработка массивов чисел и символов с помощью шаблонов
- Потоковый ввод, форматирование и запись результатов в файлы
- Выбор лабораторной работы и возврат в общее меню

## Стек технологий

- **Язык:** C++17
- **Компилятор:** Microsoft Visual C++ (MSVC)
- **Система сборки:** CMake 3.20 или новее, совместимый с установленной Visual Studio
- **Платформа:** Windows 10/11, x64
- **Работа с консолью:** Windows API
- **Автоматическая проверка сборки:** GitHub Actions

## Сборка и запуск проекта

### 1. Скачать репозиторий

На странице репозитория нажмите **Code → Download ZIP** и распакуйте архив. В корневой папке должны находиться `build.bat`, `CMakeLists.txt` и папка `src`.

### 2. Установить инструменты сборки

Установите **Visual Studio 2022 или 2026** либо **Build Tools** соответствующей версии. В Visual Studio Installer выберите рабочую нагрузку **«Разработка классических приложений на C++»** и компоненты:

- MSVC для сборки приложений x64
- Windows SDK
- Средства C++ CMake для Windows

### 3. Собрать приложение

Дважды нажмите **`build.bat`**. Он автоматически найдёт инструменты, соберёт все работы и поместит **`oop_labs.exe` в корневую папку рядом с `build.bat`**.

Окно останется открытым, чтобы можно было прочитать результат или ошибку. При повторной сборке исполняемый файл обновляется; перед этим закройте запущенное приложение.

Для запуска сборки из PowerShell:

```powershell
.\build.bat
```

Для сборки без ожидания нажатия клавиши:

```powershell
.\build.bat --no-pause
```

### 4. Запустить приложение

Дважды нажмите **`oop_labs.exe`** или выполните из папки проекта:

```powershell
.\oop_labs.exe
```

Введите номер пункта меню и нажмите Enter. После выполнения задания программа вернётся в меню. Для выхода введите `0`. В работе № 1 команда `/q` завершает текущее задание и возвращает в меню.

## Структура проекта

```text
 oop-labs/
 ├── src/                  # Код общего приложения
 │   ├── main.cpp          # Главное меню
 │   ├── labs.h            # Объявления функций запуска
 │   └── lab*.cpp          # Реализации лабораторных работ
 ├── original/             # Листинги из отчётов
 ├── .github/workflows/    # Проверка сборки на GitHub
 ├── .gitignore
 ├── CMakeLists.txt
 ├── build.bat             # Автоматическая сборка
 └── README.md
```

После сборки появляются папка `build` и файл `oop_labs.exe` в корне проекта. Они исключены из Git.

## Особенности работы

- Для вывода по координатам в работах № 1 и № 4 запускайте программу в обычной консоли Windows.
- В работе № 1 для строк разрешены печатные ASCII-символы; в работе № 2 строка ограничена 255 байтами.
- В вещественных числах используйте точку как десятичный разделитель.
- Некорректный ввод прерывает текущее задание и возвращает в меню.
- Работа № 7 сохраняет результаты в `string_result.txt` и `formatted_output.txt` в текущей папке запуска. При повторном выполнении соответствующего задания файл перезаписывается.

Исходные листинги сохранены в `original/`. В общем приложении отдельные функции `main()` заменены функциями `run()`, а одноимённые классы разделены пространствами имён. Алгоритмы лабораторных работ сохранены.

## Проверка сборки

При отправке изменений в GitHub или создании pull request workflow **Build C++ labs** автоматически проверяет сборку проекта в Windows. Результат доступен на вкладке **Actions** репозитория.
